# Convolutional Neural Network (CNN) Optimization & Feature Extraction Engine
**Domain:** Deep Learning & Machine Learning Infrastructures

## Project Abstract
This project implements a foundational, custom-built Convolutional Neural Network (CNN) built from scratch utilizing the PyTorch framework. The script sets up an automated deep learning pipeline including spatial convolutional filtering layers, ReLU activation layers, max-pooling array reduction steps, a fully-connected classifier, cross-entropy objective loss functions, and Adam optimization backpropagation loops. This acts as the structural foundation for complex real-time video array data processing.

## Core Engineering Competencies Tested
* **Deep Learning Frameworks:** Constructing tensor graphs and structural neural architecture inside PyTorch.
* **Mathematical Backpropagation Optimization:** Handling weights, bias resets, and validation losses.
* **Pipeline Vector Processing:** Efficiently managing multi-dimensional tensor arrays through spatial matrices.
